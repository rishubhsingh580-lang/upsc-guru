🔧 How to Fix "Failed to Fetch"

Browsers block API calls from local files. Run a tiny local server in 2 minutes:

OPTION 1 — Python (Easiest, already installed on most PCs)
1. Open Command Prompt / Terminal
2. Type: cd Downloads (or wherever the file is)
3. Run: python -m http.server 8080
4. Open browser → http://localhost:8080/UPSC_Guru_AI_updated.html
OPTION 2 — VS Code (if you use it)
Install the Live Server extension → Right-click the HTML file → Open with Live Server
OPTION 3 — Node.js
Run: npx serve . in the file's folder

Google Gemini API supports direct browser access — no proxy needed! If you still get errors, check your API key is valid and the model is available in your region.
